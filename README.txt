Rincón Orgánico - Landing Page
Descripción
"Rincón Orgánico" es una landing page diseñada para un restaurante de comida saludable. El sitio web está construido para ofrecer una experiencia de usuario amigable y acogedora, permitiendo a los visitantes conocer los productos destacados, revisar los horarios de atención y contactar al establecimiento de manera rápida y sencilla.

Características Principales
El proyecto está dividido en las siguientes secciones:

Navegación: Barra de navegación responsiva fijada en la parte superior para acceder fácilmente a cualquier parte del sitio.

Inicio: Una cálida bienvenida con un mensaje principal y un botón de llamado a la acción que redirige directamente a la carta.

Nuestros Productos: Una presentación visual de los platillos destacados (Ensalada César, Sándwich de pavo y Batido Purple) utilizando un sistema de tarjetas.

Horarios: Una sección clara y minimalista que detalla los días y horas de apertura.

Contacto: Un formulario intuitivo para que los clientes puedan enviar sus consultas o mensajes.

Footer: Pie de página con derechos de autor y accesos directos a las redes sociales del restaurante.

Tecnologías Utilizadas
HTML5: Para la estructura semántica de la página.

Bootstrap: Se utilizan las clases y el sistema de cuadrícula de este framework para garantizar un diseño completamente responsivo y estructurado (tarjetas, botones, formularios, navbar).

CSS3: Archivo de hojas de estilo personalizado (css/style.css) para agregar la paleta de colores del restaurante.
